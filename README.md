### Тема 2 - ViewBinding

Для комфортной работы с элементами экрана в xml разметке существует подход через ViewBinding.
Binding - переменная, предоставляющая доступ к элементам экрана без постоянного использования функции 
`findviewbyid`, из-за которой могут возникать ошибки (при указании неправильных типов, например)

Информацию по этому механизму можно получить по ссылке https://developer.android.com/topic/libraries/view-binding

В текущем шаблоне они выключены, поэтому их надо включить

Для этого в файле build.gradle уровня модуля необходимо добавить настройку, включающую этот механизм и синхронизовать проект

![img_1.png](img_1.png)

После этого необходимо поменять активити так, чтобы оно использовало описываемый подход. В случае, если этого не сделать, 
переменная binding'a не будет определена. Класс биндинга всегда строится через название файла 
разметки - каждое новое слово (слова разделяются нижними подчёркиваниями) с прописной буквы, в конце слово Binding.
Для каждого файла разметки класс биндинга свой.
