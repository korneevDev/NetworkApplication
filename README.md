### Тема 1 - Организация папок в проекте

Перед началом работы необходимо определиться с распределением кода в проекте. В Kotlin в отличие от Java нет строгих правил, где писать код и теоретически можно 
расположить все классы в одном файле, но так не делается, потому что это повышает трудность последующей работы с проектом: от написания до чтения.
Так же, можно весь код писать напрямую в активити, но такой подход опять же не является best practice, потому что такой супер компонент тяжело поддерживать.

Одним из актуальных подходов к разработке на данный момент является подход Clean architecture + MVVM, при котором в проекте выделяются слои:

- data - слой, отвечающий за работу с данными из разных источников
- domain - слой, отвечающий за работу с бизнес-логикой в проекте
- ui - слой, отвечающий за работу с отображением данных и взаимодействием с пользователями
