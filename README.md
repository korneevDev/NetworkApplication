# Проект по изучению построения приложений на android с использованием Retrofit2 + Room + MVVM + Clean architecture

## Навигация

Описание лекции находится в ветках. Для прохождения определённой темы, нужно перейти на соответствующую.

### Тема 1 - Создание проекта

Во-первых необходимо создать проект. Для этого необходимо выбрать шаблон, из которого он будет создан. 
Шаблон - заготовка кода, в которой сразу реализована какая-то логика. Для создания каркасного проекта, 
мы будем использовать Empty Views шаблон - при его использовании создаётся один компонент Activity. 
В дальнейшем можно будет создать другие необходимые вам компоненты, либо при создании новых проектов вы сможете выбирать любой

<img width="1012" height="727" alt="изображение" src="https://github.com/user-attachments/assets/ba34f3ac-6ba9-450d-bbd5-20fdd88e659a" />

На следующем экране необходимо ввести название проекта, папку, в которой он будет сохранён и указать остальные параметры - 
минимальную версию android, для которой будет поддерживаться ваше приложение (на данный момент лучше ставить 26, но этот выбор зависит от конкретного приложения)
Так же можно выбрать язык, на котором будет происходить сборка - на данный момент kotlin является актуальным рекомендуемым решением, но до сих пор остаётся много доокументации на Gradle

<img width="1606" height="905" alt="изображение" src="https://github.com/user-attachments/assets/3aae87d2-446d-46c6-b803-b2b1a2a87ceb" />

При создании нового проекта обязательно необходимо подключение к интернету, первый запуск всегда долгий из-за того, что все зависимости каждый раз заново загружаются в каждый проект.
По завершении билда проекта, среда должна перейти в режим отображения android

либо на стороннем эмуляторе) чтобы проверить корректность установки всех зависимостей.

Проект должен собраться, установиться на устройство и запуститься без ошибок
